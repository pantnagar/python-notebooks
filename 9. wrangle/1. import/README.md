# pandas data import — practice workbook

1. `pip install -r requirements.txt`
2. Open `pandas_data_import_practice.ipynb` in Jupyter / VS Code (keep the folder structure: `data/` and `mock_api.py` must sit next to the notebook).
3. Work top to bottom: predict → run → break it → exercise → recall.
4. Only open `solutions/` after you've attempted an exercise.

`make_data.py` regenerates the synthetic datasets (seeded, reproducible).
