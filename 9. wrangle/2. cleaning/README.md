# The Case of the Corrupted Applications
Learn data assessing + cleaning like a detective.

1. `pip install -r requirements.txt`
2. Open `data_assessing_and_cleaning_casebook.ipynb`, run top to bottom (Acts I-VI).
3. Do the Excel inspection in Act I.3 yourself (`data/loan_applications_raw.xlsx`).
4. `solutions/` contains the solved notebook, the hidden answer key and the data generator (it reveals every planted defect - open it only after your own verdict).

Note: if you re-run Exercise 8 (de-duplication), re-run every cell below it, since the cleaning steps build on the same `work` DataFrame.
